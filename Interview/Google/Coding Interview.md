## Steps
- Listening the question carefully and repeating the question with own words
- Ask for or come up with a couple of Examples / Test Cases
  - **Character & Constraints**: 
    - `Data Type`
    - `Sorted`, `Repeated Elements`, `Negative Number`
  - **Input/Output**:
    - `Return Type`
    - Fit in Memory or not
  - Discuss the variety of Test Case
  - **TAKE NOTE**
- Proposal:
  - Brute Force first but mention what the best I can do in this situation
  - Show Off Tool Kits: 2 Pointers / Binary Search / ...
- Implementation:
  - Explain Why the Implementation Choice and Trade Off of each Choice
  - Good Naming of Variable and Function
  - How implementation handles exceptions and edge cases
    - Negative, Repeated, **Underflow** and **Overflow**.
- Running Test Cases
  - **Basic**: Examples
  - **Edge Cases**: Empty, Boundary Numbers
- Review:
  - Check syntax and Typo
  - Time Complexity & Space Complexity
